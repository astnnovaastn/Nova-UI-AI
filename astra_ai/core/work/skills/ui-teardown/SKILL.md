# UI teardown

## Gather
- One analyst per product (at most three): the home page, pricing, sign-up and pages that show the product itself (tour, features, docs with screenshots). Record each screen's address and the design moves that stand out, quoting copy exactly.

## Result
- "Worth taking": at most eight patterns, each with why it works, where it applies and the screen it came from.
- With several products, a comparison table of the patterns that split them (yes, no or unknown).
- The product's design stance in one sentence and up to three things it gets wrong, each naming the screen.
- Colours and type only as pages state them; never guessed from a picture.
