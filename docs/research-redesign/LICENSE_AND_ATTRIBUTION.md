## Obligations when copying MPL-2.0 files

MPL-2.0 applies file by file:

1. Copied and modified files stay under MPL-2.0.
2. Keep upstream notices, and add the MPL notice to each copied file, since upstream files mostly have no header.
3. Make the source of covered files available to anyone who receives the distributed app, and tell them how to get it.
4. Include a copy of the license with any distribution.
5. AEGIS's own files can keep their license. Keep them as separate files rather than mixing them into MPL files.

## Name and logo

Upstream README: "The Zephium name and logo are not licensed under the MPL."

- Do not copy `logo.png`, `zephium-wordmark.svg`, `assets/brand/`, or the mascot artwork if it is part of the brand.
- Remove user-facing "Zephium" text from reused message strings.
- Do not present AEGIS as Zephium. Attribution such as "contains code from Zephium" is a factual notice.
