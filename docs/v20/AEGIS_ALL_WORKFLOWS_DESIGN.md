# Workflow design and capability boundaries

All workflow IDs remain the existing catalog IDs. Selection uses an explicit arrangement first, then compatible recorded family/workflow metadata, then measured topology. Saved geometry is authoritative.

| Workflow | Preferred family | Inputs and truthful completion |
| --- | --- | --- |
| explain-code | code-walkthrough | Supplied code; real file reading still unavailable |
| map-a-project | architecture-atlas | Supplied/public architecture evidence; repository inventory not implied |
| review-a-change | change-review | Supplied diff and context; no executed correction implied |
| fix-a-bug | debugging-workbench | Supplied failure and proposed correction; test runner not available |
| ui-teardown | ui-teardown | Supplied page/screenshot evidence; findings require visible regions |
| moodboard | visual-moodboard | Supplied/source-linked imagery; no artificial source captures |
| competitor-landscape | market-landscape | Evidence-backed companies and explicit unknown attributes |
| campaign-plan | timeline-milestones | Goals, drafts and actual/supplied dates; estimates labeled |
| plan-my-day | daily-schedule | Supplied tasks and dates; no calendar write |
| weekly-status | execution-board | Supplied work records; status is never inferred from dragging |
| learning-path | timeline-milestones | Objectives and checkpoints; unknown starting level remains open |
| exam-prep | mixed-result | Supplied syllabus and recorded answers |
| inbox-triage | priority-inbox | Supplied messages only; no automatic sending |
| meeting-prep | focused-answer | Supplied context; no invented participants |
| market-map | market-landscape | Sourced segments and classifications |
| pricing-research | comparison-desk | Units, dates, periods and assumptions required |
| investor-list | comparison-desk | Evidence-backed fit; no fabricated contacts |
| quick-research | focused-answer | Supported concise answer, optional specialist stages |
| deep-research | research-publication | Coverage diagnostics, citations and explicit gaps |
| knowledge-map | knowledge-constellation | Supported subject relationships; subject cycles permitted |

Loaded Skill records continue to come from the actual registry and frozen instruction snapshots. Layout labels do not activate Skills or grant tools.

Every workflow must eventually cover missing input, blocked capability, partial failure, retry, cancel and restore. Existing fake-provider tests cover research stages and publication; the full per-workflow execution matrix is not yet implemented.
