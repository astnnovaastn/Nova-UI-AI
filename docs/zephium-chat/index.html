One user turn

Open Ask on an eligible tab, choose the page context or add a selection, and send a question. The frontend sends a typed desktop request. Rust prepares page evidence, calls the Page model, and streams updates to the thread. When a step needs a decision, the panel shows the approval or takeover request. You can continue in Work through a separate handoff.

Interface and visual design

The Ask panel is lazy loaded in the browser tool rail. A shared ToolFrame supplies the surrounding panel. New chat and the menu sit in the header. The central area displays the thread, history, or saved site styles, and the composer stays in the footer. The panel dims the neighboring sidebar column while a menu is open.

Request and streaming

AssistSession subscribes before loading the snapshot, queues updates while loading, and folds events scoped to its Space. The frontend sends pageAssistAsk through generated IPC. The desktop command checks the caller and delegates to the Rust service. The service admits the request, creates a reply and dispatches the agent. Rust events update the same reply as text and tool results arrive.

Response design

The thread follows new content while the reader remains near the bottom and offers a jump-to-end button when they scroll away. PersonMessage represents the user turn. Reply renders typed blocks for prose, cited items, opened tabs, search, steps, site styles, and Work handoff. It also exposes progress, faults, copy, and the cost display when applicable. Inline citations bind to page passages. CSS and the thread both account for reduced motion.

Page reader and model

The desktop adapter supplies tab facts and the configured Page model. The engine reads a live document through closed calls in a private execution world. It can return page text, selection, element picks and a style outline. The agent builds bounded page records, gives passages stable references within the reply, and puts page-derived text in untrusted prompt blocks. The local source configures live tab reading for macOS and Windows.
